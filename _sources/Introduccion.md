# Introduccion 

En el presente trabajo se realiza el uso de las redes neuronales y **MLP(Multilayer Perceptron)** para poder predecir si un usuario hará clic en un anuncio móvil **(click = 1)** o no **(click = 0)**. 

Se realizo un extenso analisis exploratorio y preprocesamiento para poder realizar el modelado con sklearn y luego se realizo en Pyspark para poder realizar comparaciones con LIME y determinar cual fue mas efectivo.
